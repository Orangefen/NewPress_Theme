# DocsHub 1.2.0

DocsHub 1.2.0 是面向文档、开发教程和知识库站点的完整主题增强版本。

- 新增 15 组、121 项主题设置，覆盖外观、导航、首页、文档列表、文章阅读、系列、评论提示、404 和页脚。
- 扩充首页模块控制、推荐数量、文案与布局联动；完善列表视图、卡片封面和筛选入口。
- 完善文章目录层级、阅读工具、正文排版和系列上下篇导航。
- 优化导航选中态、响应式布局、移动端菜单和无脚本快捷入口。
- 设置支持预览、导入导出、恢复默认值、旧设置兼容和无效值拒绝。

本版本使用 NewPress `public/v1`，无需迁移文章、页面或站点数据。安装包 SHA-256 为 `bbdbd41d0e3a2d1748109753b16407bf07475f1b29bb5fdbafa28652a3746f2c`，大小为 2,235,378 字节。

本版本收录于 `catalog.themes-v1.json` 序号 3，以 stable 通道发行。进入 NewPress 后台「主题市场」刷新目录即可安装并使用 DocsHub 1.2.0；已安装的 DocsHub 1.0.0 仍保留，可按站点需要升级。

发布前已完成主题构建、核心模板渲染、主题设置集成测试、桌面与移动端布局检查，以及源码、安装包和本地安装目录的逐文件一致性核对。
