# Nexora 1.1.0

Nexora 1.1.0 是面向科技企业官网的完整主题增强版本。

- 新增 21 组、186 项主题设置，覆盖外观、布局、首页模块、企业事实、合作伙伴、常见问题、新闻、联系资料、导航和文章阅读。
- 完善首页区块联动、内容排序、企业事实/合作伙伴/FAQ 空值处理、新闻筛选分页和专题系列。
- 优化轮播暂停与恢复、移动菜单焦点管理、导航选中态、阅读目录、评论回复和验证适配器。
- 保留 `public/v1` 核心边界、旧设置兼容、无脚本导航和原有站点数据。

本版本无需迁移文章、页面或站点数据。安装包 SHA-256 为 `5dbb43bd9d49dbe6570edea3aa9b87db9c777255225e12bf6aba7142e5bf8dbd`，大小为 686,233 字节。

本版本收录于 `catalog.themes-v1.json` 序号 4，以 stable 通道发行。进入 NewPress 后台「主题市场」刷新目录即可安装并使用 Nexora 1.1.0；已安装的 Nexora 1.0.1 仍保留，可按站点需要升级。

发布前已完成主题构建、63 项前端测试、核心模板与集成检查，并验证桌面和移动布局无横向溢出。
