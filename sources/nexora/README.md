# Nexora · 科技企业官网

独立的 `public/v1` 企业主题。按所提供的 NEXORA 参考图实现冷蓝建筑首屏、透明导航、宋体双行标题、关于我们、四栏优势和山峦愿景区，并延伸为完整的业务、新闻、人才、合作与页脚页面。

## 直接使用

主题源码位于本仓库的 `sources/nexora`，需要单独安装。在 NewPress 部署目录执行 `newpress theme install <nexora-1.0.1.zip绝对路径>`，启动后到「主题市场」使用此主题。核心源码包不包含 Nexora。

需要主题边界重构后的 NewPress 核心；旧版本不能解析 `view: public/v1`。新主题没有修改现有站点的活动主题或生产内容。

1. 在核心「站点设置」中设置企业名称、标语、站点图标、SEO 和备案。参考图中的品牌名为 NEXORA；主题实际显示核心站点名称。
2. 在「外观与主题」中配置 52 项展示设置：配色、标志图片、三张轮播文案、建筑与山峦图片、介绍、优势、业务与联系链接。留空的图片使用内置素材。
3. 在核心「导航菜单」中分配主导航或页脚导航。未配置菜单时显示企业首页锚点和新闻中心；明确配置为空的菜单保持为空。支持三级菜单和新窗口链接。
4. 通过核心内容管理发布真实企业页面和新闻，再把按钮指向对应的 `/pages/<slug>`。首页展示最多三篇公开文章，新闻中心使用核心搜索、分类与分页。
5. 联系按钮可配置为企业联系页。未配置时，根据核心反馈模块状态进入在线留言或用户中心。

首屏轮播默认手动切换，支持按钮、圆点与方向键。手机菜单支持 Escape 和焦点循环；搜索使用原生表单和可关闭对话框。没有 JavaScript 时仍可使用首屏、主导航、搜索、新闻阅读和普通评论表单。开启评论验证时需要 JavaScript。

## 边界

- 主题只包含公共展示模板、样式、图片、字体和浏览器交互；没有管理模板、数据库、密钥或新增后端路由。
- 品牌身份、正文、发布状态、菜单、媒体、评论、账号、支付和模块开关归核心所有。
- 未覆盖的账号、结算、反馈等系统页面由核心提供。前台配色不影响后台。
- 未声明 `home-layout/v1`；企业首页用自己的展示设置组织内容，不调用 Chunnel 首页组件或布局编辑器。
- 评论使用核心原生提交协议；独立 `nexora-verification` 适配器只负责验证 UI，验证凭据的签发、消费、风控与权限仍由核心执行。站点未开启验证时不加载这个脚本。
- 主题设置中的介绍和业务描述是展示文案；正式长文和企业资料可通过核心页面管理。默认文案是可替换的参考内容。

## 构建、检查、打包

在独立主题仓库根目录运行：

```powershell
npm ci
npm run build
npm run check
npm test
python scripts/check_core.py --core "../newpress"
npm run package
```

发布包为 `packages/themes/nexora-1.0.1.zip`，无需安装 Node、Python 或生图 API 即可运行。发行目录见仓库根目录的 `PUBLISHING.md`。

修改源文件后重新构建并重启开发实例。主题资源路径带内容摘要；运行期间直接修改文件会使原版本资源地址失效。

字体为独立授权的本地宋体子集，约 67 KiB；没有加载 Chunnel/B2 字体。默认标题字形包含在子集中，未收录的新字由系统宋体回退。图片为 WebP，首屏约 168 KiB。素材来源、许可与生图提示词见 [素材说明](ASSETS.md) 和 [第三方许可](THIRD_PARTY_NOTICES.md)。
