# DocsHub · 文档与教程

DocsHub 1.2.0 是独立的 NewPress `public/v1` 主题，适合产品文档、技术知识库、开发教程和课程站点。

默认界面保留玻璃丝带首屏、218px 桌面侧栏、圆角搜索框、四列快捷入口、教程卡片、最新文档和社区学习路径。文字、按钮、导航和列表由 HTML 模板生成，装饰图像随主题以 WebP 提供。支持首页、文章、独立页面、搜索、分类/标签归档、作者、学习系列、404 和维护页；账号、后台和权限由 NewPress 核心提供。

1.2.0 提供 15 组、121 个主题设置，覆盖外观、布局、导航、首页内容、列表与阅读工具。完整字段、优先级和三种配置示例见 [主题设置指南](SETTINGS.md)。

## 安装与设置

使用本地安装包：

```powershell
newpress theme install <docshub-1.2.0.zip 的绝对路径>
```

安装后在「主题市场」选择 DocsHub；如运行实例未重新加载主题，重启后再检查。进入「外观与主题」(`/admin/appearance/`) 调整配置并保存。主题设置的预览、导入、导出和恢复默认值沿用核心机制。

站点名称、图标、语言、版权和备案在核心配置。主导航、更多资源和页脚分别对应 `primary`、`utility`、`footer` 菜单；已配置菜单优先，显式配置的空菜单保持为空。默认入口使用真实站内搜索，建议将快速开始、API、常见问题和社区地址改为本站对应内容。语言菜单展示站点语言。

首页教程和最新文档默认各显示 4 篇，可分别设置为 1–8 篇。主题只使用核心已提供的公开文章，实际数量还受站点首页文章数和内容数量限制；教程优先使用精选集合（有数据时）。安装包不创建演示文章，空站点显示空状态。关闭推荐区后，默认「浏览教程」锚点自动转向文档中心。

外观默认浅色，可设置为深色或跟随系统。允许访客切换时，浏览器保存的偏好优先；关闭切换后采用站点默认值。预览忽略已有访客偏好。禁用 JavaScript 时，深色配置仍生效，跟随系统使用浅色；正文、搜索表单和基本导航仍可使用。

宽屏支持调整内容与侧栏宽度；760px 以下使用抽屉导航。文章支持二至四级目录、阅读进度、时间估算、代码复制、连续阅读和讨论，可分别关闭。文档中心、作者和归档页面支持默认卡片/列表视图；有效 URL 视图参数在脚本运行后优先。页面提供键盘焦点、跳过导航、移动抽屉焦点约束，并尊重减少动态效果偏好。

## 1.2.0 更新

- 设置分为品牌与外观、导航与搜索、公告、首屏、首页模块、首页文档、社区与学习路径、入口链接、文档列表、文章阅读、系列、讨论、错误恢复、页脚及快捷入口 15 组；每项对应实际模板、样式或交互。
- 首页模块可独立开关，推荐/最新数量、说明、按钮、快捷入口和学习步骤均可调整；少量内容、隐藏插画及关闭侧栏模块时自动适配布局。
- 浅色、深色和跟随系统支持访客偏好、管理员锁定与隔离预览。新增导航密度、宽度、固定工具栏、公告及辅助入口设置。
- 卡片可使用装饰封面、仅真实封面或纯文字；列表筛选、排序、视图入口可独立控制，已有筛选条件保留清除入口。
- 阅读工具和元信息可独立关闭，目录层级与正文排版可调整，隐藏全部侧栏项后自动收为单栏；可选显示真实的同系列推荐。
- 讨论提示、404 内容及默认页脚入口可定制，评论权限、模块开关、维护内容和核心页脚信息继续由核心管理。

保留 1.1.0 的唯一导航选中、嵌套分支展开、筛选条件保留、移动目录同步、系列首尾边界、评论回复/取消及表单验证。

## 资源与模块

模板位于 `templates/partials/`，按外壳、首页、列表、阅读和评论拆分；`assets/js/modules/` 按导航、状态规则、搜索、阅读、评论、外观及公共函数组织；`assets/css/modules/` 分离基础、布局、首页、列表、阅读、评论、系列、设置、深色和响应式样式。修改后需要重新构建，浏览器加载打包后的独立 CSS/JS。

未配置文章封面时默认使用随包的四张装饰图，也可改为只显示真实封面或隐藏全部封面。真实封面使用核心提供的响应式尺寸。主题使用设备本地中文字体，不请求外部字体、图片服务或前端框架。原 Noto Sans SC 子集和许可保留用于追溯。素材清单见 [ASSETS.md](ASSETS.md)。

## 开发验证

在独立主题仓库根目录运行：

```powershell
node scripts/build_theme.mjs --source sources/docshub
node scripts/build_theme.mjs --source sources/docshub --check
node --test tests/frontend/docshub-state.test.cjs tests/frontend/docshub-appearance.test.cjs
npm test
python scripts/check_core.py --core ../newpress --theme docshub
```

启动隔离浏览器夹具：

```powershell
python scripts/check_core.py --core ../newpress --theme docshub --ui
```

夹具使用 `http://127.0.0.1:19107/`、临时主题目录和内存内容。修改源码后重启夹具。`NEWPRESS_DOCSHUB_UI_STOP` 可指定一个尚不存在的文件路径；创建该文件后夹具退出。检查默认值和自定义配置时，覆盖首页、列表、文章、系列、空状态、深浅色及窄屏。

发行使用新的版本与包名，避免覆盖已有安装包。安装包制作不等于发布到主题市场。
