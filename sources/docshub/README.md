# DocsHub · 文档与教程

DocsHub 1.0.0 是一个独立 NewPress `public/v1` 主题，面向产品文档、技术知识库、开发教程和学习站点。

按提供的 1254 × 1254 参考图实现：218px 固定侧栏、481px 玻璃丝带首屏、圆角搜索栏、四列快速入口、教程卡片、最新文档和社区学习路径。文字、按钮和内容列表都由 HTML 模板构成，装饰图像为本地 WebP。

支持首页、文章、独立页面、搜索、分类/标签归档、作者文章、专题与学习系列、404 和维护页。文章页自动生成二三级目录、阅读时间和代码复制按钮，提供系列上下篇、评论与人机验证。账号、后台和权限使用 NewPress 核心。

桌面参考宽度为 1254px；980px 以下使用双列教程卡片，760px 以下提供抽屉导航，480px 以下社区区改为单列。浅色为默认，可切换并保存深色偏好；支持键盘导航、跳过导航、移动导航焦点约束及减少动效偏好。

## 安装

在停止占用主题目录的 NewPress 实例后执行：

```powershell
newpress theme install <docshub-1.0.0.zip 的绝对路径>
```

重启后进入「主题市场」，点击 DocsHub 的「使用此主题」。站点名来自核心「站点设置」。主题设置可调整强调色、首屏标题与介绍、教程区标题、社区标题和所有快捷入口链接。主导航、更多资源、页脚分别使用 `primary`、`utility`、`footer` 菜单；显式配置的空菜单会保持为空。

默认入口使用真实站内搜索，例如「API 参考」搜索 API，「快速开始」搜索入门；建议将入口改为本站的具体文档、学习系列或已配置的社区地址。「观看演示」默认定位到教程区，可替换为站内演示文章或视频页面。语言菜单显示站点配置的语言，不会伪造未配置的翻译页面。

首页教程和最新文档均读取核心提供的公开文章，教程优先采用契约中的精选内容（如存在）。未配置首页布局能力时展示最近四篇公开文章。安装包不创建内容；空站点展示清楚的空状态。示例标题与正文仅存在于隔离测试夹具中。卡片使用真实发布日期，不伪造阅读量或阅读时长；文章阅读时长由实际正文估算。

未设置文章封面时，使用随包附带的四张装饰封面；上传实际封面后自动使用内容封面和核心响应式尺寸。使用本地 Noto Sans SC 可变字体子集，无运行时外部字体下载、图片服务或前端框架依赖。素材来源见 [ASSETS.md](ASSETS.md)。

## 开发验证

在独立主题仓库根目录运行：

```powershell
node scripts/build_theme.mjs --source sources/docshub
node scripts/build_theme.mjs --source sources/docshub --check
python scripts/check_core.py --core ../newpress --theme docshub
python scripts/check_core.py --core ../newpress --theme docshub --ui
```

可交互夹具使用 `http://127.0.0.1:19107/`、临时主题目录与内存数据，不触碰运行中站点。更新源码后重新启动夹具。`assets/images/preview.webp` 是实际运行页面截图；发行时使用新文件名打包，避免覆盖既有版本。
